# Dashboard pig images

Place the four supplied images in this directory with these names:

- `pig_mud.png` - measurement station map tab
- `pig_water.png` - calendar and work plan tab
- `pig_grass.png` - RAG evidence tab
- `pig_sparkle.png` - data tab

The dashboard displays each image at the same 150px width. PNG, JPG, and WEBP are supported by Streamlit, but keep the filenames above or update `_PIG_ASSETS` in `app/dashboard.py`.
