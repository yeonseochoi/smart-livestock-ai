# 익산시 축산 악취 민원 저감 의사결정 시스템

> ⚠️ **API 키 노출 — 조치 필요**
> `demo/legacy/kma.py` 에 기상청 폴백 서비스키가 하드코딩되어 있고 이 저장소는 공개 상태다.
> **키 폐기 후 재발급이 필요하다.** `legacy/` 는 수정 금지 원칙이 걸려 있으므로
> 배포 사본에서 치환하거나 별도 조치를 취한다.

**"냄새 나는 작업을 언제 하면 민원이 덜 날까"를 시각 단위로 답하는 시스템.**

농가가 액비를 뿌리거나 분뇨를 반출할 때, 앞으로 3~7일 중 어느 시각이 가장 안전한지
순위를 매겨 준다. 익산시 실제 악취 민원 6년 반치(13,039건)와 기상 실측을 학습했다.

```
   입력   기상청 단기예보(D+1~3, 1시간) + 중기예보(D+4~7, 일 단위)
   출력   시각별 위험 등급 + 추천/회피 시각 + 저감 조치 조언
   성능   시가지 test ROC-AUC 0.899 · A등급 시각의 민원율이 전체 평균의 1/17
```

---

## 30초 요약

이 시스템은 **두 개의 서로 다른 질문**을 서로 다른 도구로 답한다. 섞지 않는 것이 설계의 핵심이다.

| 질문 | 도구 | 쓰이는 곳 |
| --- | --- | --- |
| **언제** 민원이 나는가 | XGBoost (통계) | 위험 등급 결정 — 판단의 주체 |
| **어디로** 냄새가 가는가 | 가우시안 플룸 (물리) | 어느 수용점 유형을 볼지 *선택*만 |

**두 모델을 곱하지 않는다.** 바람과 주야간이 양쪽에 모두 들어가 있어 곱하면 이중 계산이 된다.
플룸은 등급을 올리거나 내리지 않고, ML 이 이미 매긴 점수 중 **어느 것을 볼지 고르는 데만** 쓴다.

## 빠른 시작

```powershell
pip install -r demo/requirements.txt
cd demo

python run_train.py     # 학습   — 데이터 정제부터 모델 저장까지 (약 3분)
python run_serve.py     # 서빙   — 예보 받아 위험도 계산 + 작업시각 추천
python run_check.py     # 검증   — 회귀 점검 39항목
```

세 명령이 전부다. 중간 산출물과 모델 파일은 커밋되지 않으며 위 명령으로 재생성된다.

API 키는 전부 선택사항이다. `KMA_KEY`·`VWORLD_KEY`·`ANTHROPIC_API_KEY` 가 없으면
mock 폴백으로 돌고, **폴백을 탔다는 사실이 콘솔에 반드시 찍힌다.**

## 지켜야 하는 규칙 4가지

전부 실제로 사고가 난 뒤에 생긴 규칙이다.

```
   ① 서빙 피처는 예보에 있는 변수만
      NH3·CO2 를 넣는 순간 "학습은 되는데 예측은 못 하는" 모델이 된다.
      암모니아는 예보가 존재하지 않는다.

   ② ML 과 플룸을 곱하지 않는다
      역할 분담만 한다. 등급은 ML 단독, 플룸은 대상 선택.

   ③ 민원 데이터는 반드시 익산 필터 후 사용
      원본에 완주군이 8.3% 섞여 있다. 필터 후 5,654건이 정상값이다.

   ④ 임의 상수엔 [C] 딱지를 붙인다
      좌표 상수 하나가 3.35km 어긋나 검증이 통째로 뒤집힐 뻔한 적이 있다.
      이 규약 덕에 잡았다.
```

## 알려진 한계

솔직하게 적어 둔다. 발표에서 먼저 말하는 편이 낫다.

```
   ① 살포 기록이 세상에 없다
      y=0 이 "안전했다"인지 "아무도 안 뿌렸다"인지 구분할 방법이 없다.
      상관을 학습해 인과를 주장하는 구조적 간극이 남는다.

   ② 악취 저감이 아니라 민원 저감이다
      야간 민원 81.5% 가 역전층 때문인지, 그저 신고 가능한 시간이어서인지 모른다.

   ③ 민원의 26.2% 는 김제 발원이다
      익산 농가를 대상으로 하는 서비스의 효과 상한선이다.

   ④ 학습은 관측, 서빙은 예보
      예보 오차로 인한 성능 열화를 아직 측정하지 못했다.

   ⑤ 확률이 보정되지 않았다
      순위는 유효하지만 절대값(0.23 같은 숫자)은 신뢰할 수 없다.
```

이 한계 때문에 우리는 **"민원을 줄여 준다"** 고 말하지 않고
**"상대적으로 위험한 시각을 피하도록 돕는다"** 고 말한다.
